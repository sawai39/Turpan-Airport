## 核心字段清单

### 基础航班信息

| 字段名称 | 数据来源 | 样例数据 | 说明 |
|---------|----------|----------|------|
| 航班号 | dflt_info表的awcd+flno | GJ 8652 | 统一显示，不分进/出港 |
| 航段（三字码） | dflt_airl_arpt_info表的apcd | URC | 本站三字码 |
| 航司 | dflt_info表的awcd | 南方航空 | 航空公司名称 |
| 机型 | dflt_info表的cftp | B738 | 机型代码 |
| 机号 | dflt_info表的cfno | B7198 | 飞机注册号 |
| 进/出港 | dflt_info表的flio | 出港 | 进港(A) / 出港(D) |
| 机位 | dflt_stls_stnd_info表的code | 239 | 停机位编号 |
| 跑道 | dflt_info表的rway | 26R | 使用的跑道 |

### 时间信息

| 字段名称 | 数据来源 | 样例数据 | 说明 |
|---------|----------|----------|------|
| 计划起飞/落地 | dflt_airl_arpt_info表 | 2025-12-09 15:25:00 | 出港看计划起飞，进港看计划落地 |
| 实际起飞/落地 | dflt_airl_arpt_info表 | 2025-12-09 17:33:00 | 同上 |
| COBT（撤轮档） | ygwzhjc_sys_dispatch表 | 15:03:00 | 计算撤轮档时间 |

### 行李与旅客信息

| 字段名称 | 数据来源 | 样例数据 | 说明 |
|---------|----------|----------|------|
| 出港旅客人数 | passenger_cargo表的loading_num | 152 | 值机人数 |
| 出港行李件数 | passenger_cargo表的load_luggage_weight | 136 | 配载行李重量（kg），可转为件数估算 |
| 进港旅客人数 | passenger_cargo表的loading_num | 146 | 进港航班用 |
| 进港行李件数 | passenger_cargo表的load_luggage_weight | 128 | 进港行李重量 |

### 保障节点（行李相关）

| 字段名称 | 数据来源 | 样例数据 | 说明 |
|---------|----------|----------|------|
| 开货舱门时间 | ygwzhjc_sys_dispatch表 | 17:48:00 | 节点为"开货舱门"的实际结束时间 |
| 关货舱门时间 | ygwzhjc_sys_dispatch表 | 18:15:00 | 节点为"关货舱门"的实际结束时间 |
| 当前节点 | ygwzhjc_sys_dispatch表 | 行李装卸 | 仅展示与行李相关的节点 |

### 异常与状态

| 字段名称 | 数据来源 | 样例数据 | 说明 |
|---------|----------|----------|------|
| 航班状态 | dflt_info表的abst | 延误 | 正常、延误等 |
| 异常原因 | dflt_info表的abrs,iars | 行李传送车到位延后 | 影响行李配送的原因 |
| 延误状态 | dflt_info表的abst | 延误 | 同航班状态 |
| 延误原因 | dflt_info表的abrs,iars | 机位冲突 | 细化原因 |

### 字段显示策略

- **APP端（精简版）**：航班号、机型、机号、进/出港、机位、计划/实际时间、旅客人数、行李件数、行李转盘号、航班状态、当前节点
- **中台端（完整版）**：上述全部字段

### 1.2 呼叫行李车弹窗

**页面布局：**
```
┌─────────────────────────────────────────┐
│           呼叫行李车                  │
├─────────────────────────────────────────┤
│  ┌───────────────────────────────────┐  │
│  │ 航班号: GJ 8652                   │  │
│  │ 机型: B738                        │  │
│  │ 配送类型: 行李下机                │  │
│  └───────────────────────────────────┘  │
├─────────────────────────────────────────┤
│  行李车数量:                           │
│  ┌──────┐ ┌─────────┐ ┌──────┐        │
│  │  -   │ │    4    │ │  +   │        │
│  │(减1) │ │(推荐值) │ │(加1) │        │
│  └──────┘ └─────────┘ └──────┘        │
│  (根据机型B738默认推荐4辆)             │
├─────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐    │
│  │    取消      │  │    确认      │    │
│  └──────────────┘  └──────────────┘    │
└─────────────────────────────────────────┘
```

**交互说明：**
- 弹窗显示航班号、机型、配送类型等信息
- 根据机型自动计算并显示推荐行李车数量（默认4辆）
- 支持点击"+""/-"按钮调整数量（范围：1-10辆）
- 点击"确认"按钮创建订单并分配对应数量的行李车任务
- 点击"取消"按钮关闭弹窗，不创建订单

## 原型设计说明

### 设计原则
1. **简洁高效**：界面布局清晰，操作流程直观
2. **安全优先**：急停等关键操作采用双重保障
3. **实时反馈**：状态信息及时更新，操作有明确反馈
4. **移动端适配**：APP端考虑手机屏幕尺寸和触控操作

### 色彩规范
| 状态 | 颜色 | 说明 |
| ---- | ---- | ---- |
| 空闲 | 绿色 | 车辆可分配 |
| 运输中 | 蓝色 | 正在执行任务 |
| 充电 | 黄色 | 充电状态 |
| 故障 | 红色 | 需要维修 |
| 待处理 | 橙色 | 等待操作 |

### 交互规范
- 点击按钮有按压反馈效果
- 状态变更有动画过渡
- 异常情况有声音/视觉双重提醒
- 重要操作需二次确认
