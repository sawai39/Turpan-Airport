## 原型设计说明

### 设计原则
1. **简洁高效**：界面布局清晰，操作流程直观
2. **安全优先**：急停等关键操作采用双重保障
3. **实时反馈**：状态信息及时更新，操作有明确反馈
4. **移动端适配**：APP端考虑手机屏幕尺寸和触控操作

### 色彩规范
| 状态 | 颜色 | 说明 |
| ---- | ---- | ---- |
| 空闲 | 绿色 | 车辆可分配 |
| 运输中 | 蓝色 | 正在执行任务 |
| 充电 | 黄色 | 充电状态 |
| 故障 | 红色 | 需要维修 |
| 待处理 | 橙色 | 等待操作 |

### 交互规范
- 点击按钮有按压反馈效果
- 状态变更有动画过渡
- 异常情况有声音/视觉双重提醒
- 重要操作需二次确认
